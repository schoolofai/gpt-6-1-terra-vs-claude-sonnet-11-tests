Create `semver.js` (ES module, no dependencies) exporting `satisfies(version, range)` returning true/false, following npm semver range rules (node-semver behaviour), without using the semver package. Support:
- exact versions, comparators `>`, `>=`, `<`, `<=`, `=`, combined with spaces (AND) and `||` (OR)
- caret `^` and tilde `~` ranges, including the special cases for 0.x and 0.0.x
- X-ranges (`1.x`, `1.2.*`, `*`, `""`) and partial versions (`1`, `1.2`)
- hyphen ranges (`1.2.3 - 2.3.4`, `1.2 - 2.3`)
- prerelease versions: a prerelease version only satisfies a range if some comparator in the same comparator set has the same major.minor.patch with a prerelease tag; prerelease precedence must follow the SemVer spec (numeric vs alphanumeric identifiers).
- Invalid versions return false.
