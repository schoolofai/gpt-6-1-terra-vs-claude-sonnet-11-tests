Create `ratelimit.js` (ES module, no dependencies) exporting `createLimiter({ capacity, refillPerSec, now })`.
- It is a token bucket: starts full with `capacity` tokens and refills continuously at `refillPerSec` tokens per second, never above capacity. Fractional refill accumulates.
- `now` is an optional function returning the current time in milliseconds (default `Date.now`). Never read the clock any other way.
- `limiter.take(key, cost = 1)` returns `{ ok, remaining, retryAfterMs }`. Each key has its own bucket. If enough tokens: subtract, ok=true, retryAfterMs=0. Otherwise take nothing, ok=false, and retryAfterMs is the exact whole number of milliseconds (rounded up) until the request would succeed. `remaining` is the whole number of tokens left (floored).
- A cost larger than capacity can never succeed: return ok=false and retryAfterMs=Infinity.
- Cost must be a positive finite number, otherwise throw a TypeError.
- If the clock goes backwards, treat elapsed time as 0 (never remove tokens).
Do not ask questions. Write tests if you like, then finish.
