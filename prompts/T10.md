Create `bookings.py` (Python 3.11+, standard library only) with `merge_bookings(bookings: list[tuple[str, str]]) -> list[tuple[str, str]]`.
Each booking is (start, end) as ISO-8601 strings. Rules:
- Strings with an offset or `Z` are absolute times. Strings with no offset are wall-clock times in Europe/London.
- A London wall time that does not exist (inside the spring-forward gap) is invalid: raise ValueError. An ambiguous wall time (the repeated hour when clocks go back) means the FIRST occurrence (BST).
- end must be strictly after start, otherwise raise ValueError.
- Merge bookings that overlap or touch (end == next start) into one.
- Return merged bookings sorted by start, each as UTC strings in the exact form `YYYY-MM-DDTHH:MM:SSZ`.
Do not ask questions. Test your work, then finish.
